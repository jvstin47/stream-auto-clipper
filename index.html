Turn Live Streams into Viral Reels Automatically

An open-source highlight extraction pipeline and AI agent skill. Detects hype moments, renders 9:16 vertical videos, and generates esports-style cover thumbnails with safe-zone bounds.

View on GitHub Quickstart Guide

Core Capabilities

⚡

Multimodal Peak Detection

Scans raw 16-bit audio loudness peaks alongside video frame motion variance to pinpoint genuine high-energy moments.

⏱️

Dynamic Duration (30s – 75s)

Avoids rigid cuts. Clips dynamically adapt based on action continuity so punchlines and clutches are captured fully.

📱

Vertical 9:16 Synthesis

Supports stacked facecam layout with automated face detection or landscape fit with blurred background padding.

🎨

Mobile-Safe Thumbnails

Extracts sharp action frames, applies pro color grading, and centers 150pt display typography safely within 1:1 Instagram profile grids.

🚀

Multi-Platform Publishing

Cross-posts rendered highlights directly to Instagram Reels and YouTube Shorts with proper thumbnail bindings.

🤖

AI Agent Skill Ready

Includes complete skill instructions so AI coding agents can discover and execute clipping workflows autonomously.

Quickstart in 3 Steps

# 1. Clone repository and install dependencies

git clone https://github.com/jvstin47/stream-auto-clipper.git

cd stream-auto-clipper

pip install -r requirements.txt


# 2. Configure streamer and game branding

cp config.example.json config.json


# 3. Extract top 5 highlights and generate thumbnails

python stream_clipper.py --file gameplay.mp4 --count 5
